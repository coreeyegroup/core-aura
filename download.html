First install or upgrade an older app

  1. Download the APK and open it from Downloads.
  2. Allow installation from the download source if Android asks.
  3. Confirm Install or Update, then open Core-aura.

In version 0.22.0 and later, use Settings → Android app updates → Update latest. Updates download inside Core-aura. Supported Android versions can update directly; Android may ask for confirmation. Install this release over an older stable app once to get that updater; keep the installed app and its saved data.

Moving from the earlier test APK?

The earlier test APK has a temporary signing key. Export your practices, affirmation library and recordings first. Replace that test app once with this stable app, then import your backups. This replacement is needed only for the test-to-stable transition.

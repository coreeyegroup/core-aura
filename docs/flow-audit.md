# Core-aura flow audit — v0.18.0

Audit scope: the existing web/PWA and shared native interface, including Home → tool → editor → playback → save → schedule → Library, Back/Forward, reload, offline use and unavailable server services. This is a source and automated browser audit; physical Android/iOS acceptance remains separate.

## Persistence and connectivity boundaries

- Existing practices, affirmation categories, recordings, downloaded packs and saved sessions keep their existing storage schemas.
- New composer/workspace keys are device-local and bounded. A malformed sound workspace is preserved and reported instead of silently overwritten. A storage write failure is reported; playback is never resumed automatically after reload.
- Canonical routes support Schedule, affirmation categories, recordings, saved practices, audio Library and sound packs. Browser Back/Forward restores those destinations. Only current selection/context is encoded; sentence text and private practice content are not placed in URLs.
- Server health checks are public readiness requests, run when their Settings panel is opened. Local synthesis and installed content do not require server readiness. Internet connectivity does not guarantee delivery of a notification.

## Remaining work

1. Unified portable backup/restore of practices, affirmation library, recordings, settings and schedules; browser storage alone is not an independent backup.
2. Physical Android/iOS testing for hardware Back, audio interruptions, microphone permissions, sharing, battery/background behavior and notification delivery. Native production signing/store delivery is still pending.
3. Cross-device accounts and synchronization, separately authenticated content reviewers, resumable pack downloads and recovery from browser storage eviction.
4. Musical/tradition review and licensed repertoire; clinical evidence is required before health-treatment or regeneration claims.

These are pending product/platform capabilities, not claims that the original full project requirements are complete.
